# 18. Azahar/Citra チートコード（所持金・ジュエル）

自分のゲーム・エミュ上の単機能チート。所持金とジュエルは平の値ではなく
ビットパック変数（docs/16）なので、固定アドレスを書くAR方式が使えない。
代わりに**取得関数 `ScriptFlag::GetGold` / `GetJewel` を定数リターンに
書き換える**。両方ともARMのサンクなので、3本の32bit書き込みで

```
LDR r0, [pc, #0]   ; E59F0000   PC+8 の .word を r0 に
BX  lr             ; E12FFF1E
.word <値>
```

に置き換わる。AR行 `0AAAAAAA VVVVVVVV` は「アドレス 0AAAAAAA に 32bit
VVVVVVVV を書く」（先頭ニブル0＝32bit書き込み）。

## v1.17.0（アップデート適用後、Title ID `0004000E00125D00`）

```
[Gold max (always 999,999,999)]
00191DD4 E59F0000
00191DD8 E12FFF1E
00191DDC 3B9AC9FF

[Jewels max (always 9,999)]
00191E24 E59F0000
00191E28 E12FFF1E
00191E2C 0000270F
```

値を変えるなら 3行目の `.word` を書き換える（ジュエルは上限9999＝`270F`、
所持金は上限999999999＝`3B9AC9FF`）。
`tools/mkcheat.py --gold 50000 --jewels 500` で生成し直せる。

## v1.0.0（アップデート未適用、Title ID `0004000000125D00`）

関数の形は同じでアドレスだけ違う:

```
[Gold max]
00184C14 E59F0000
00184C18 E12FFF1E
00184C1C 3B9AC9FF

[Jewels max]
00184C48 E59F0000
00184C4C E12FFF1E
00184C50 0000270F
```

## 入れ方（Azahar）

ゲームを右クリック → **Properties → Cheats → Add New Cheat**、または
`<Azaharユーザーディレクトリ>/cheats/<TitleID>.txt` に
[`cheats/0004000E00125D00.txt`](../cheats/0004000E00125D00.txt) を置く。

## 注意

- これは**実行中の表示・判定を書き換えるだけ**で、セーブファイルには
  書き込まない。チートON中は所持金・ジュエルが常に最大で表示され、
  購入判定も通る。**OFFにすると元の値に戻る**（セーブに永続しない）
- エミュのJITは変換済みブロックをキャッシュするため、コードパッチ系
  チートはタイミングによって効かないことがある（docs/07の注意と同じ）。
  効かない場合はゲーム起動前にチートを有効化してから起動する
- セーブそのものにジュエルを増やして**配布したい**場合は、このチートでは
  永続しない。1.17.0のセーブ（所持金かジュエルが非ゼロのもの）を
  `tools/varedit.py` で直接書き換える必要がある（docs/16）。
  オフセット特定のため、全ゼロでない1.17.0セーブが要る
