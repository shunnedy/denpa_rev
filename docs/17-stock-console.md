# 17. 無改造の3DSでどこまでできるか

CFWを入れていない本体で、このゲームについて何ができて何ができないか。
根拠はすべてこのリポジトリの解析結果（ROM・`code.bin`・exheader）。

## 結論の要約

| | 無改造 | 根拠 |
|---|---|---|
| ローカル通信対戦 | **今も動く** | `nwm::UDS` + `LocalBattleButton.arc`、サーバ非依存 |
| ダウンロードプレイ | **今も動く** | `dlp:FKCL` / `dlp:SRVR` |
| すれちがいバトル | **今も動く**（直接すれちがい） | `cecd:u` + `streetPassWinPrize.bin` |
| コロシアム（オフライン） | **今も動く** | 対戦相手がROM内の30表（docs/15） |
| 季節のセリフ | **おそらく動く**（本体時計依存、未検証） | 下記 |
| 期間限定イベントの賞品 | 動かないと見られる | チェックインで有効化される設計 |
| チェックイン（イベント配信） | **不可** | 証明書ピン留め（下記） |
| Ｗｉ-Ｆｉコロシアム・ランキング | **不可** | 同上 |
| キャンペーンコード | **不可**（ローカル版も） | 下記 |
| ジュエル購入 | **恒久的に不可** | eShop閉鎖 |
| MOD・自作イベント・サーバ差し替え | **不可** | LayeredFS / IPS / 3GX はCFW前提 |

**このリポジトリで作ったもの（docs/07・12・13・14）はすべてCFWかエミュレータが前提**で、
無改造本体には適用できない。

## なぜサーバ系が無改造で不可能なのか

無改造本体でも**手動DNS設定はできる**（本体設定のインターネット設定）。
しかしそれだけでは届かない。

1. ゲームのエンドポイントは**9本すべてHTTPS**（docs/13）。平文HTTPは
   証明書内のCRL配布URL1件だけで、抜け道にならない
2. ゲームは `la1.denpamen.com` の証明書（1334バイトのDER）を
   **ピン留め**している（docs/07）。差し替えたサーバが同じ証明書を
   出せない限りハンドシェイクで落ちる
3. 秘密鍵はバイナリに入っていない（PEMヘッダ0件、PKCS#1秘密鍵パターン0件、
   rsaEncryption OIDは証明書自身の公開鍵の1件だけ）
4. 無改造本体には**CAを追加できない**
5. プロキシ設定も同じ理由で効かない（HTTPSはトンネルされるだけ）

加えて、リクエストヘッダ `101` に **NNIDのprincipal ID** が要る
（`act:u` の `GetAccountDataBlock(0xFE, 4, 0xC)`、docs/13）。
3DS向けのアカウントサーバは停止済み。

## キャンペーンコードも無改造では使えない

ROM内に表はある。

| テーブル | レコード | 所在 |
|---|---|---|
| `CampaignCodeLocal` | 50 × 88B | updateのみ |
| `CampaignCodeNetwork` | 137 × 88B | updateのみ |
| `CampaignCodeAddParty` | 132 | updateのみ |
| `CampaignCharacter` | 32 | updateのみ |

レコードの中身を列ごとに調べると、**報酬と表示メッセージしか入っていない**:

```
+ 0  ID参照（3種）          種別
+56  プール参照（50件すべて異なる）  コード入力時に出る文面
+60  ID参照（4種）          報酬の種類
+64  ID／生値（33種）        報酬の中身
+68  生値（3種）            個数
+84  ID参照（22種）
（+4〜+52 と +72〜+80 はゼロか 0xD0D0D0xx のフィラー）
```

ID配列の値は **0〜55の小さい番号**で、プレイヤーが入力する
コード文字列ではない。つまり**コード→レコードの対応はコード側にある**
（ハッシュか変換）。ネットワーク版は `campaigncodeserver` で検証するので
どちらにしても無改造では通らない。

## 季節のセリフは本体時計で動いていると見られる（推測）

`MessageNagomiFriend`（2,117件）に、日付を知っていないと出せない
セリフが大量に入っている:

```
今日はハロウィンですね。あなたは仮装とかしないんですか？
今日はクリスマスですか。あなたのご予定は？
あの、誰かにチョコをあげる予定とかありますか？
ハッピーハロウィン！ボクの家にくるなら仮装してね♪
```

「なごみ」のフレンド会話は `nagomi*` 系のローカルテーブルから選ばれる
仕組みで、日付の出どころは本体時計しかない。したがって
**本体の日付を変えれば無改造でも季節のセリフは見られる**可能性が高い。

いっぽう `HalloweenPrize`（8件）・`EggHunt`（11件）・`EggPrize`（8件）は
**賞品の表**で、イベントそのものの開催はチェックインで有効化される設計
（docs/09・11）。表がROMにあっても、開催フラグが来ない以上
日付を変えただけで賞品がもらえるとは限らない。

**どちらも未検証。** 確かめるには実機かエミュで日付を変えて試すのが早い。
解析側で詰めるなら、時計を読んで月日で分岐している箇所を
Ghidraで追うことになる（今回は月日のバイト対を機械的に探したが
誤検出だらけで決め手にならなかった）。

## 無改造でできることの実際の上限

- **本編を最後まで遊ぶ** — 配信要素以外は全部ローカル。アップデートで
  メインストーリーが `AfterMS0040` → `AfterMS0300` まで伸びているので
  （docs/11）、アップデート済みなら相当な分量がある
- **コロシアム** — ランク1〜5 × 6段の30チームがROM内。日替わりの
  ランク上昇も本体時計で進む（「明日になるまでランクは上がらない」）
- **釣り・ハウジング（なごみ）・クイズ** — すべてローカルテーブル
- **2台あればローカル通信対戦とすれちがいバトル** — サーバは元から不要
- **本体の日付を変えて季節のセリフを見る** — 上記の推測の範囲で

## 無改造では永久に無理なもの

- **配信限定のレア電波人間157体**（docs/11の一覧）。`lotRareDenpa_Limited_1`〜`12`
  などの抽選表はROMにあるが、抽選を開くのはチェックインで配信される
  イベント。サーバが無く、証明書ピン留めで差し替えもできない
- **EVCK系の配信イベント**（コードに01/04/21/30、データは18/19のみ）
- **全国討伐イベントの集計**
- **ランキング・Ｗｉ-Ｆｉコロシアム**
- **ジュエル購入**（eShop閉鎖）

これらを復活させたいなら CFW が必要で、その手順は docs/14 にある。
