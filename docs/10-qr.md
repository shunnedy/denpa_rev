# 10. QR機能は存在しない（結論）

電波人間シリーズはQRコードで電波人間を交換できるのが特徴で、
電波人間のRPG3 では QR の暗号が Blowfish(ECB) + CRC-32/BZIP2 で解けている。
FREE! にも同じ仕組みがあるかを3方向から確認したが、**いずれも否定的**。

| 調べたこと | 結果 |
|---|---|
| `code_dec.bin`（base / update）に RPG3 の Blowfish 鍵 `d0959870cfe0feaebbaef0d670fbbdf0` | 見つからない（正順・逆順とも） |
| Blowfish の P配列の初期値 `243f6a88`（円周率由来、BE/LEとも） | 見つからない |
| 文字列 `QR` `qrcode` `Blowfish` `2S3D` `1_3D` | QR関連の該当なし（`QR` の一致はbase64アルファベット `...NOPQRSTU...` の部分一致のみ） |
| ゲームテキスト19,344件に `QR` `ＱＲ` の語 | **0件** |

テキスト検索で引っかかった「キャッチ」51件はすべて**電波キャッチ**
（アンテナでカメラ越しに電波人間を捕まえる本編のミニゲーム）の文脈で、
QRとは無関係:

```
キャッチされちゃったみたいですね。お見事です。
キャッチは安全なところで、周りに迷惑をかけないようにね。
```

exheader に `cam:u`（カメラ）はあるが、これは電波キャッチのAR用途。

したがって FREE! でのキャラクター配布・交換は
**QRではなくサーバ配信（`checkinserver`）とキャンペーンコード入力**
（docs/09）で行われていたと結論する。
